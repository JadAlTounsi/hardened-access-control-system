# ADR-004: Lockout enforcement location

**Status:** Accepted

**Date:** 08/12/2026

## Context
When a lockout happens due to too many failed attempts, the camera controller captures an image and uploads it to the dashboard with a timestamp.

With this, I need to figure out where I should store the failed attempt count and the lockout threshold, either on the dashboard or on the controller itself.

## Decision
Track all the failed attempts and enforce the lockout threshold on the main controller.

The main controller counts the failed attempts locally, and once the threshold is hit, it will enforce the lockout for the specific person, and sends a capture request to the camera controller.

The camera controller captures the photo and uploads it with the timestamp to the dashboard as a lockout event.

## Consequences
- Positive: Lockout enforcement will not depend on network connectivity or the dashboard being reachable.
- Negative: Open to attacks through flooding the main controller.
