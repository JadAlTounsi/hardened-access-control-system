# ADR-002: Running camera on a dedicated microcontroller

**Status:** Accepted

**Date:** 07/31/2026

## Context
We have 34 usable GPIO pins. Camera claims 14 GPIO pins, SDcard slot uses 3 GPIO pins, PSRAM uses 3 GPIO pins, strapping pins use 4 GPIO, and the USBs use 2 GPIO pins. This leaves us with 8 pins to use which won't be enough to incorporate the input devices needed for this system. We require around 17-20 pins if we use a keypad, screen, reader, servo, and buzzer.

## Decision
Use an ESP32-S3 CAM module for the camera, and an ESP32-S3-DevKitC for the rest of the input devices.

## Consequences
- Positive: Isolates the camera from the main access control logic. If the camera had a faulty, it won't affect the main system.
- Negative: Linking both devices together requires more code which can cause a new point of failure.
